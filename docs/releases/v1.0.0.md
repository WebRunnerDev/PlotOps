## Highlights

**PlotOps 1.0** is the first stable release of a git-native project tracker — Kanban, sprints, in-app GitHub PRs and diffs, and a real GitHub Actions CI/CD dashboard in one product.

**Live:** [plotops.webrunner.dev](https://plotops.webrunner.dev) — sign in with GitHub, Google, or email; or use **Try demo** for a local Guest sandbox (no account required).

## What's in 1.0

### Auth & onboarding

- GitHub + Google OAuth and email signup with confirmation
- Complete-profile gate, OAuth unlink, and Wave 3 auth hardening (Turnstile CAPTCHA, rate limits)
- Local **Guest Mode** — client-side sandbox via “Try demo” (ADR 0018)
- Sign-in on the landing page with shared route gate and SEO-friendly public routes

### Teams, projects & permissions

- **Team → Project** hierarchy with Owner / Manager / Member / Viewer roles
- Team invites (redeem links, optional Resend edge function)
- GitHub project import on the home page; connect or attach repos later
- Git/CI empty states until a repository is linked

### Kanban & tasks

- Multi-board per project with custom columns, labels, priority, deadlines, and filters
- Drag-and-drop with optimistic updates; hide-completed toggle; priority rail on cards
- Subtasks as full tasks, parent progress badge, link existing board tasks as subtasks
- Task Links (`blocks` / `relates`) with Done-gating; inline create-and-link in the links section
- Soft archive, comments with one-level replies, activity feed
- Rich text descriptions (TipTap): images, tables, `@` mentions, `#` task links, code-block copy
- Project custom text fields (Settings CRUD + drawer; built-in Description)
- Shareable task URLs with drawer sync and deep links
- Board/backlog task search toolbar; shift-click range select; double-click to open

### Sprints

- Board-scoped sprints: Backlog, Start / Close / Cancel, estimates, burndown, insights
- Fibonacci estimates; Close uses Done column; closed sprint retains completed members (ADR 0021)

### Git & CI/CD

- Branch generate / link / skip; link PR; in-app code diff and smart commit discovery
- Open PR and Merge from the task drawer (ADR 0022); PR check runs rollup (ADR 0025)
- CI/CD dashboard on **real GitHub Actions** — filters, jobs, logs, infinite scroll
- GitHub webhook: PR merge → move task to Done column on the board base branch

### Product UX

- Command palette (`Ctrl`/`Cmd`+K): search, create, navigate, switch project, toggle theme
- Watch / assignment notifications, structural kinds, `@` mentions inbox
- Legal pages (privacy & terms, EN/RU); static SEO, sitemap, and SSG prerender
- Cross-browser public-route smoke tests in CI (Chromium, Firefox, WebKit)

### Engineering

- Supabase PostgreSQL with RLS; migrations applied via CI on `main` (ADR 0016)
- Migrate-before-deploy pipeline: schema push → Cloudflare Pages Deploy Hook
- Feature-Sliced Design, TanStack Router + Query, React 19, Tailwind 4, shadcn/ui

## Upgrade notes

- **First public release** — no migration from a previous tag.
- **Operators:** configure `VITE_SUPABASE_URL`, `VITE_SUPABASE_PUBLISHABLE_KEY`, GitHub App / webhook secrets per `docs/SUPABASE.md` and `docs/github-webhook-setup.md`.
- **Schema:** all committed migrations in `supabase/migrations/` are applied automatically when this commit lands on `main`.
