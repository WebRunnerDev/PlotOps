# Multiple Active Sprints per Board

A Board may run any number of Active Sprints at once (parallel workstreams). Task membership stays at most one Sprint. Kanban Active scope is the union of Active members with a multi-select filter; create requires an Active picker when more than one Active is selected; Close may Carryover incomplete Tasks to another Active on the same Board. Supersedes the “at most one Active per Board” rule in ADR 0008.
