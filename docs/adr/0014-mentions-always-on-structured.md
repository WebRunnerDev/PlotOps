# Mentions are always-on structured references, not Watcher noise

PlotOps needs @-style Mentions in Task Description and Comment with inbox delivery to the Mentionee. We treat Mention as its own always-on Notification kind (fan-out at write time, ADR 0010), independent of Watch — Mentionees are not auto-enrolled as Watchers (ADR 0012 stake rules unchanged). Mentions are structured rich-text references keyed by user id; free-text `@Name` is not a Mention. On edit, only newly added Mentionees relative to the previous body are notified. The app extracts Mentionee ids from the body and calls an RPC; the RPC validates each Mentionee is a current Project Owner or Member, excludes the actor, applies the new-only delta, and inserts fan-out rows — no Postgres HTML-parse trigger. This reopens the Mentions deferral in ADR 0011 without broadening Watch to Comments or description edits.

**Rejected:** Watcher kind for every Comment; auto-Watch on Mention; regex/`@displayName` parsing as the source of truth; re-notify unchanged Mentionees on every save; purge existing Mention Notifications when a Mentionee leaves the Project; group Mentions (`@everyone` / whole Roles); DB trigger that parses Description/Comment HTML for Mentions.
