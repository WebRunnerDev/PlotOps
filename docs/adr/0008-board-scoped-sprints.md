# Board-scoped Sprints with commitment at Start

Sprints belong to a Board (not Project/Team): timebox + Task container only — columns stay on the Board. At most one Active Sprint per Board; many Drafts allowed. Start snapshots Commitment; later add/remove on Active are Scope changes. Completion is decided only in the Close dialog (pre-suggest Done column via `is_done`); Cancel returns all Tasks to the Backlog. Manager+ owns lifecycle/membership; Contributor views. Estimates (ADR 0020) optionally enrich size display and client-side burndown; membership metrics remain count-based when points are absent.
